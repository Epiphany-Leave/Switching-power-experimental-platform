# 3D 模型 / 3D models

本目录收录电路板和磁性元件的三维模型，以及迷你隔离变压器的 EDA 库资料。

| 目录 | 内容 / Contents |
| --- | --- |
| [G7半桥](G7半桥/) | G7 半桥模块 STEP 模型 / G7 half-bridge module STEP model |
| [NSM2015](NSM2015/) | NSM2015 模块 STEP 模型 / NSM2015 module STEP model |
| [平面磁](平面磁/) | ERI2150 的 STEP 与 SolidWorks 零件文件 / ERI2150 STEP and SolidWorks part |
| [辅助电源](辅助电源/) | 平板变压器、LM5164 和 SY8401 板卡 STEP 模型 / planar transformer, LM5164 and SY8401 board STEP models |
| [迷你隔离变压器](迷你隔离变压器/) | 微型变压器 STEP、SolidWorks 零件、嘉立创 EDA 封装及器件库 / transformer STEP and SolidWorks part, EasyEDA footprint and device library |

`.step` / `.STEP` 可在支持 STEP 的 CAD 软件中查看或导入；`.SLDPRT` 为 SolidWorks 零件文件。`.elibz` 为嘉立创 EDA 器件库，`.efoo` 为封装文件；库内的 3D 模型引用可能需要在 EDA 中重新关联本目录的 STEP 文件。

Open `.step` / `.STEP` in a STEP-compatible CAD tool and `.SLDPRT` in SolidWorks. The `.elibz` device library and `.efoo` footprint are for EasyEDA; the library's 3D model reference may need to be linked to the local STEP file.
